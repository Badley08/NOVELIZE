# NoveLize SFX Checklist

List of 50 sound effects commonly needed for light novels (fantasy, isekai, action, school life, mystery). Put an **X** in the first column when the sound is downloaded.

**Progress: 0 / 50**

## Guidelines

* **Format:** MP3 is fine (Android plays it natively), so no conversion is needed. Keep each effect short (1 to 5 seconds); ambient loops 30 to 60 seconds. If a loop clicks or has a gap when it restarts, convert that file to OGG.
* **File names:** use the name in the last column, in lowercase with underscores.
* **Loop:** "Yes" means the sound must loop seamlessly (ambient and continuous sounds).
* **Pixabay:** sounds can be used in the app, but Pixabay forbids redistributing its files as-is on a standalone basis. Do not commit the raw sound files to the public repository (keep them out of Git, or download them through the first-run wizard). Sounds marked CC0 have no such limit.
* **Licenses:** prefer CC0 sounds. For CC-BY sounds, write the author and source in the credits file so they can be listed in the app. Avoid sounds ripped from games, anime, or films.
* **Voices:** avoid sounds that contain spoken words, so they do not clash with the narration.
